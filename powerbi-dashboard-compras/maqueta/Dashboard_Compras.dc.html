Antes de los gráficos: qué validar en tus datos

Lo que tienes que definir o pedir en la exportación del ERP:

IGV: trabaja con montos sin IGV y escríbelo en el subtítulo de cada página.

Tipo de movimiento: incluye devoluciones y anulaciones. Si sumas todo, el gasto sale inflado. Crea una tabla de tipos de movimiento con una columna Signo (+1 / −1 / 0).

Tiempo de atención: con una sola fecha no se puede calcular. Necesitas dos, por ejemplo la de solicitud o de OC y la de recepción. Si el ERP no las tiene, deja el KPI como mejora futura y explícalo; es mejor que inventar el dato.

Número de OC y material o familia: pídelos. Sin el número de OC no puedes medir el ticket promedio, y sin la categoría no hay análisis de gasto por categoría, que es lo más valorado en compras.

2026 está incompleto: compara el acumulado del año contra el mismo periodo del año anterior, y calcula la variación mensual solo con el último mes cerrado.

Modelo estrella (es lo primero que revisa un reclutador técnico)

  • Una tabla central de compras.
  • Dimensiones: Calendario, Proveedor, Tipo de movimiento y Centro de costo.
  • Centro de costo debe llevar la unidad de negocio: Manufactura, Distribución o Servicios.

Medidas DAX base

Gasto Neto = SUMX ( Fact_Compras, Fact_Compras[MontoPEN] * RELATED ( Dim_TipoMovimiento[Signo] ) )

Gasto AA = CALCULATE ( [Gasto Neto], SAMEPERIODLASTYEAR ( Dim_Calendario[Fecha] ) )
Var % vs AA = DIVIDE ( [Gasto Neto] - [Gasto AA], [Gasto AA] )

Gasto Mes Anterior = CALCULATE ( [Gasto Neto], DATEADD ( Dim_Calendario[Fecha], -1, MONTH ) )
Var % MoM = DIVIDE ( [Gasto Neto] - [Gasto Mes Anterior], [Gasto Mes Anterior] )

Gasto YTD = TOTALYTD ( [Gasto Neto], Dim_Calendario[Fecha] )

Proveedores Activos = CALCULATE ( DISTINCTCOUNT ( Fact_Compras[ProveedorKey] ), Dim_TipoMovimiento[Signo] = 1 )

Nro OC = DISTINCTCOUNT ( Fact_Compras[NroOC] )
Ticket Promedio OC = DIVIDE ( [Gasto Neto], [Nro OC] )

Monto Devuelto = CALCULATE ( SUMX ( Fact_Compras, Fact_Compras[MontoPEN] ), Dim_TipoMovimiento[EsDevolucion] = TRUE () )
% Devoluciones = DIVIDE ( [Monto Devuelto], [Gasto Neto] + [Monto Devuelto] )

-- Pareto: % acumulado del proveedor en el ranking
% Acumulado Pareto =
VAR GastoProv = [Gasto Neto]
VAR Total = CALCULATE ( [Gasto Neto], ALLSELECTED ( Dim_Proveedor ) )
VAR Acum =
    SUMX (
        FILTER (
            ADDCOLUMNS ( ALLSELECTED ( Dim_Proveedor[Proveedor] ), "@g", [Gasto Neto] ),
            [@g] >= GastoProv
        ),
        [@g]
    )
RETURN DIVIDE ( Acum, Total )

Proveedores 80% =
COUNTROWS (
    FILTER ( ALLSELECTED ( Dim_Proveedor[Proveedor] ), [% Acumulado Pareto] <= 0.8 )
) + 1
